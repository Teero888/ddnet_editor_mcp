# DDNet editor MCP server
To use it, start the client, open the editor and start the MCP server on any free port.
<img width="1455" height="586" alt="image" src="https://github.com/user-attachments/assets/3e1e9aff-db25-428b-814c-88cace6cd513" />

After that any AI agent can freely control the editor with 90 different tool calls. AI particularly excels at design so it might be useful in someway. It is absolutely terrible at gameplay though unless heavily assisted by you, so please don't submit any maps with AI gameplay to KoG/DDNet.
